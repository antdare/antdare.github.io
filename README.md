# antdare.github.io
CS-331-A: Data Visualization
Assignment 1
Let’s kick things off with a creative coding assignment that plays with how we visualize time. Choose one of your clock sketches from our in-class exercise—or develop a new one—and bring it to life as a functioning clock that runs in the browser using p5.js. 

It doesn’t need to look or behave like a traditional one, but it should still be readable. A viewer should be able to tell the hour, minute, and second (or at least estimate the time within ~15 minutes).
